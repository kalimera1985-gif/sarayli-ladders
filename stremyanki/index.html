Как выбрать стремянку SARAYLI

По материалу

Сталь дешевле и тяжелее, выдерживает агрессивную эксплуатацию. Алюминий — для частых перемещений, не ржавеет. Двусторонние — для команд из двух работников.

По высоте

Считайте по рабочей высоте — это сумма роста человека (≈1,8 м) и высоты площадки. Для потолка 2,7 м хватит 3 ступеней (1103/2103). Для склада 4 м — 6–7 ступеней.

По нагрузке

Все стремянки SARAYLI выдерживают 150 кг. Это вес монтажника (90 кг) + инструмента (15 кг) + материалов (45 кг) с большим запасом.
